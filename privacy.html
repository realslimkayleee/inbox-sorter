Inbox Sorter – Privacy Policy

Last updated: October 30, 2026

Inbox Sorter is a private tool used only by its owner to organize the owner's own Gmail account. It is not available to the public.

What Google data it accesses

With the owner's permission, Inbox Sorter reads email messages, senders, subjects, and attachments in the owner's Gmail account, and adds or removes Gmail labels so messages are sorted into folders.

How the data is used

Email content is used only to decide which label a message should receive. Inbox Sorter never permanently deletes email.

Storage and sharing

Inbox Sorter runs on the owner's own computer. Google user data is not sold, not shared with third parties, and not used for advertising. Access can be revoked at any time at myaccount.google.com/permissions.

Inbox Sorter's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
